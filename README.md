# 🤖 AI Study Planner

## 📌 Project Overview

AI Study Planner is a simple web-based application designed to help students organize their study activities and plan their study time effectively. The application uses **Python Flask** for the backend and **HTML and CSS** for the frontend, providing a simple and user-friendly study planning interface.

## ✨ Features

* 📚 Organize study activities
* ⏰ Manage study time
* 📅 Create a structured study plan
* 📝 Enter and manage study details
* 🎨 Simple and user-friendly interface
* 🌐 Flask-based web application

## 🛠️ Technologies Used

* **Python** – Backend programming
* **Flask** – Web application framework
* **HTML5** – Web page structure
* **CSS3** – User interface styling
* **Visual Studio Code** – Development environment

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/ai-study-planner.git
```

### 2. Open the Project

Open the downloaded project folder in **Visual Studio Code**.

### 3. Install Flask

Open the VS Code terminal and run:

```bash
python -m pip install flask
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

Open the following address in your browser:

```text
http://127.0.0.1:5000/
```
